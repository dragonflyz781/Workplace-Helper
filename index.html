Almost there – connect Firebase

This app needs a free Firebase project to store companies, drivers and routes.

  1. Create the project (see README.md, section 1).
  2. Open js/firebase-config.js and paste in your project's values.
  3. Reload this page.

Just want to look around first? If you are running this on your own computer, open http://localhost:5000/?emulator=1 after running npm run demo (see README, section 3).
